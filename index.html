Предпросмотр

Так подпись увидит получатель. Снимите все галочки ролей — блок «Точки роста» исчезнет, останется обычная подпись Ростелекома.

Как установить подпись

Outlook

  1. Нажмите «Скопировать подпись» на этой странице.
  2. В Outlook откройте Файл → Параметры → Почта → Подписи…
  3. Нажмите «Создать» и введите название, например «Точка роста».
  4. Кликните в поле «Изменить подпись» и нажмите Ctrl+V.
  5. Справа в «Выбор подписи по умолчанию» выберите её для новых сообщений и для ответов и пересылки.
  6. Нажмите ОК. Проверьте результат: создайте новое письмо.

Новый Outlook и Outlook в браузере

  1. Нажмите ⚙ Параметры → Учётные записи → Подписи.
  2. Нажмите «Новая подпись», задайте название и вставьте подпись (Ctrl+V).
  3. Ниже выберите её для новых сообщений и ответов, нажмите «Сохранить».

Картинки в подписи огромные? Это старая версия подписи. Удалите её в «Подписях», заново нажмите «Скопировать подпись» на этой странице и вставьте ещё раз — теперь картинки встают в нужном размере.

Логотип не появился? Поставьте курсор над строкой с ролями, нажмите в редакторе подписи кнопку «Рисунок» и выберите файл логотипа (скачать).

Evolution

  1. Нажмите «Скопировать подпись» на этой странице.
  2. В Evolution откройте Правка → Параметры → Параметры редактора, вкладка «Подписи».
  3. Нажмите «Добавить». В окне редактора подписи включите формат HTML (меню «Формат» или переключатель в панели).
  4. Введите название подписи, кликните в поле и нажмите Ctrl+V. Нажмите «Сохранить и закрыть».
  5. Откройте Правка → Параметры → Учётные записи почты, выберите вашу учётную запись → «Изменить».
  6. На вкладке «Составление сообщений» в поле «Подпись» выберите созданную подпись и нажмите ОК.

Письма уходят без оформления? Evolution может писать простым текстом. В окне нового письма выберите формат HTML — или включите его по умолчанию в параметрах редактора.

Подпись сделана таблицей с инлайн-стилями — так она одинаково выглядит в Outlook, Evolution и веб-почте. Логотип «Точки роста» встроен внутрь подписи. Данные, которые вы вводите, никуда не отправляются и хранятся только в вашем браузере.
